# Weather Intelligence Dashboard

A web-based weather dashboard built for a 2nd-year computer science project. This application fetches and displays real-time weather forecasts, air quality index (AQI) data, and allows for side-by-side city temperature comparisons.

## Features
*   **Current Weather & AQI:** Displays temperature, wind speed, and real-time Air Quality Index using Open-Meteo APIs.
*   **7-Day Forecast:** Visualizes maximum and minimum temperature trends using Chart.js.
*   **Weather Alerts:** Simulates local weather alerts for extreme conditions (e.g., high temperatures or high winds).
*   **City Comparison Tool:** Allows users to input two different cities and compare their upcoming 7-day temperature trends on a bar chart.

## Technologies Used
*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Data Visualization:** [Chart.js](https://www.chartjs.org/)
*   **APIs:** [Open-Meteo Weather API](https://open-meteo.com/), Open-Meteo Air Quality API, Open-Meteo Geocoding API

## How to Run
1. Clone or download this repository.
2. Open `index.html` directly in your web browser (no local server required).
3. Ensure you have an active internet connection to load the Chart.js CDN and fetch API data.
